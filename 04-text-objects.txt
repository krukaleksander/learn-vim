================================================================================
                          VIM MOTIONS - TEXT OBJECTS
================================================================================
Text objects let you operate on structured chunks of text.
Format: {operator}{a|i}{object}
  - 'a' = "a" (around) - includes delimiters/whitespace
  - 'i' = "inner" - excludes delimiters/whitespace
================================================================================

================================================================================
                          TEXT OBJECTS CHEATSHEET
================================================================================
WORD/CHARACTER OBJECTS:
iw / aw    - Inner word / A word (includes surrounding space)
iW / aW    - Inner WORD / A WORD
is / as    - Inner sentence / A sentence
ip / ap    - Inner paragraph / A paragraph

QUOTE OBJECTS:
i" / a"    - Inner double quotes / Around double quotes
i' / a'    - Inner single quotes / Around single quotes
i` / a`    - Inner backticks / Around backticks

BRACKET OBJECTS:
i( / a(    - Inner parentheses / Around parentheses (alias: ib / ab)
i{ / a{    - Inner curly braces / Around curly braces (alias: iB / aB)
i[ / a[    - Inner square brackets / Around square brackets
i< / a<    - Inner angle brackets / Around angle brackets

TAG OBJECTS:
it / at    - Inner tag / Around tag (HTML/XML)

COMMON PATTERNS:
ciw        - Change inner word (change word under cursor)
di"        - Delete inner quotes (empty the string)
da(        - Delete around parentheses (delete parens too)
yi{        - Yank inner braces (copy object contents)
vat        - Visual select around tag (select entire element)
================================================================================
