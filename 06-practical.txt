# Scenario 1: Rename Variable
# Task: Rename 'oldVar' to 'newVar' throughout this function
# Technique: Use * to find, ciw to change, n. to repeat
# ──────────────────────────────────────────────────────────────────────────────
function processData(oldVar) {
    if (oldVar === null) {
        return null;
    }
    const result = transform(oldVar);
    console.log("Processing:", oldVar);
    return oldVar.map(item => item * 2);
}

Steps:
1. Position cursor on 'oldVar'
2. * to search for word
3. ciwnewVar<Esc> to change first occurrence
4. n to find next
5. . to repeat change
6. Repeat n. until done

# Scenario 7: Duplicate and Modify Lines
# Task: Create variations of a line
# Technique: Use yy to yank, p to paste, then modify
# ──────────────────────────────────────────────────────────────────────────────
BEFORE:
const STATUS_PENDING = 'pending';

AFTER (create multiple status constants):
const STATUS_PENDING = 'pending';
const STATUS_ACTIVE = 'active';
const STATUS_COMPLETED = 'completed';
const STATUS_CANCELLED = 'cancelled';
const STATUS_FAILED = 'failed';

Steps:
1. yy to yank the line
2. p to paste below
3. f_ to jump to underscore
4. w to move to the start of the status name (e.g., PENDING)
5. ve (or vE) to visually select the status name
6. cACTIVE<Esc> to change it (or rA for single letter, or use s for substitute)
7. f' to jump to the string value
8. ci'active<Esc> to change the value
9. Repeat for other statuses

# Scenario 9: Convert Between Quote Types

AFTER:

# Scenario 13: Comment/Uncomment Code
# Task: Toggle comments on multiple lines
# Technique: Use Visual Block mode (Ctrl-v)
# ──────────────────────────────────────────────────────────────────────────────
BEFORE:
function debug() {
    console.log("Debug 1");
    console.log("Debug 2");
    console.log("Debug 3");
}

AFTER (commented out):
function debug() {
    // console.log("Debug 1");
    // console.log("Debug 2");
    // console.log("Debug 3");
}

Steps to comment:
1. Move to first console.log line
2. Ctrl-v to enter Visual Block mode
3. jj to select 3 lines
4. I// <Esc> to insert comment prefix

Steps to uncomment:
1. Ctrl-v on first //
2. jj to select 3 lines
3. ll to select // characters
4. d to delete

# Scenario 15: Complete Refactoring Exercise
# Task: Refactor this entire code block
# ──────────────────────────────────────────────────────────────────────────────
BEFORE:
var x = function(a,b,c) {
var temp = a + b
    var result=temp*c
if(result>100){
return "big"
}else{
return "small"
}
}

AFTER:
const calculateResult = function(first, second, multiplier) {
    const sum = first + second;
    const result = sum * multiplier;
    if (result > 100) {
        return "big";
    } else {
        return "small";
    }
};

Changes needed:
1. var → const (ciw)
2. x → calculateResult (ciw)
3. a,b,c → first, second, multiplier (ci()
4. Fix indentation (=ap or manual >>)
5. Add missing semicolons
6. Fix spacing around operators

================================================================================
                          EFFICIENCY TIPS
================================================================================
1. Count before motion: 5j is faster than jjjjj
2. Use text objects: ciw is faster than bcw
3. Use search: /pattern is faster than many w presses
4. Use . to repeat: saves retyping commands
5. Use macros for repetitive tasks: qq to record, @q to replay
6. Combine operators: gUiw (uppercase word), gu$ (lowercase to end)
7. Use marks for jumping: ma to set, 'a to jump
8. Use Ctrl-o / Ctrl-i to navigate jump history

================================================================================
                        COMMAND COMBINATIONS REFERENCE
================================================================================
ciw     - Change inner word
caw     - Change a word (including space)
ci"     - Change inside double quotes
ca"     - Change around double quotes (includes quotes)
ci(     - Change inside parentheses
ca(     - Change around parentheses
ci{     - Change inside curly braces
dit     - Delete inside tag
dat     - Delete around tag (entire element)
yap     - Yank a paragraph
dap     - Delete a paragraph
=ap     - Auto-indent a paragraph
gUiw    - Uppercase word
guiw    - Lowercase word
g~iw    - Toggle case of word
>>      - Indent line right
<<      - Indent line left
==      - Auto-indent current line
J       - Join lines
gJ      - Join lines without space
xp      - Transpose characters (swap)
ddp     - Transpose lines (swap)
