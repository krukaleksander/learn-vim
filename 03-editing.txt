================================================================================
                            EDITING CHEATSHEET
================================================================================
x        - Delete character under cursor
X        - Delete character before cursor
dw       - Delete from cursor to start of next word
de       - Delete from cursor to end of word
d$  / D  - Delete from cursor to end of line
d0       - Delete from cursor to beginning of line
dd       - Delete entire line
{n}dd    - Delete n lines

cw       - Change from cursor to start of next word
ce       - Change from cursor to end of word  
c$  / C  - Change from cursor to end of line
cc  / S  - Change entire line

yw       - Yank (copy) from cursor to start of next word
y$       - Yank from cursor to end of line
yy  / Y  - Yank entire line

p        - Paste after cursor/below line
P        - Paste before cursor/above line

r{char}  - Replace single character with {char}
R        - Enter Replace mode (overwrite)

u        - Undo last change
Ctrl-r   - Redo (undo the undo)
.        - Repeat last change

J        - Join current line with next line
================================================================================
